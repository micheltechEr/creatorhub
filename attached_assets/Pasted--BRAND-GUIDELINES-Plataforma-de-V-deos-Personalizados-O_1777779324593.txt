# BRAND GUIDELINES
## Plataforma de Vídeos Personalizados

---

## OVERVIEW

Marketplace profissional de vídeos personalizados que conecta artistas de elite com clientes corporativos, influencers e personalidades que buscam conteúdo customizado de alta qualidade.

**Tone of Voice**: Sofisticado, confiável, preciso. Sem informalidade.
**Visual Identity**: Minimalista, elegante, estruturado. Tipografia refinada.

## 2. TIPOGRAFIA

### Fonte Principal: **Plus Jakarta Sans**
- Moderna, geométrica, profissional
- Pesos: Regular (400), Medium (500), SemiBold (600), Bold (700)
- Excelente legibilidade em telas
- Usado em: body, UI elements

### Fonte Complementar: **Crimson Text**
- Serif elegante, clássica
- Pesos: Regular (400), SemiBold (600)
- Usado apenas em: títulos principais (H1), hero section, quoted text

## 7. TRANSITIONS & ANIMATIONS

### Standard Easing
```
Fast: 150ms cubic-bezier(0.4, 0, 0.6, 1)
Standard: 200ms cubic-bezier(0.25, 0.46, 0.45, 0.94)
Smooth: 300ms cubic-bezier(0.25, 0.46, 0.45, 0.94)
Slow: 400ms ease-in-out
```

### Hover Effects

**Button Hover:**
- Shadow increase (Elevation 1 → Elevation 2)
- Subtle transform: translateY(-1px)
- Duration: 200ms

**Card Hover:**
- Shadow increase (Elevation 1 → Elevation 3)
- Transform: translateY(-4px)
- Duration: 300ms

**Link Hover:**
- Color change to #C9A961
- Underline appears (2px dashed)
- Duration: 200ms

### Focus States (Accessibility)
```css
/* Buttons */
outline: 2px solid #0A0A0A
outline-offset: 2px

/* Inputs */
box-shadow: 0 0 0 3px rgba(10, 10, 10, 0.1)
border-color: #0A0A0A
```

## 12. ACCESSIBILITY

### Color Contrast Ratios
- Body text: 4.5:1 minimum (WCAG AA)
- Large text (18px+): 3:1 minimum
- UI components: 3:1 minimum

### Focus Management
- All interactive elements: visible focus
- Focus ring: 2px solid, 2px offset
- Tab order: logical, left-to-right

### Semantic HTML
- Use `<button>` for buttons
- Use `<a>` for navigation
- Use `<form>`, `<label>`, `<input>`
- Use heading hierarchy (h1, h2, h3)

### ARIA Labels
- Images: alt text sempre
- Buttons without text: aria-label
- Modals: aria-modal="true"
- Panels: aria-hidden on backdrop
