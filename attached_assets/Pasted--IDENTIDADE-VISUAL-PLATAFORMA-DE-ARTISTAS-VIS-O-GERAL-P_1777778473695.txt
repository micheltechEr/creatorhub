# IDENTIDADE VISUAL - PLATAFORMA DE ARTISTAS

## VISÃO GERAL
Plataforma que conecta clientes com artistas para criar vídeos personalizados. É um marketplace criativo onde a qualidade, confiança e expressão artística são centrais. O design deve refletir modernidade, criatividade e profissionalismo.

## 16. ACESSIBILIDADE

### Contrast Ratios
- Text principal sobre background: mín. 4.5:1 (WCAG AA)
- Large text: mín. 3:1
- UI components: mín. 3:1

### Focus Indicators
- Todos os elementos interativos devem ter focus visível
- Usar outline: 2px solid com offset 2px

### Color Blindness
- Não depender apenas de cor para comunicar info
- Usar ícones + text
- Exemplo: ✓ + "Sucesso" em verde

### Keyboard Navigation
- Tabindex lógico
- Tab order faz sentido
- Enter/Space para ativar

### Screen Readers
- Alt text em imagens
- Aria labels em buttons sem texto
- Semantic HTML (button, link, input, etc)
